# ResumidorIA

Projeto de automação desenvolvido em PowerShell.

## Objetivo

Monitorar uma lista de links e processar novos conteúdos
automaticamente utilizando IA.

## Tecnologias

- PowerShell
- Git
- GitHub
- APIs de IA

## Status

Em desenvolvimento.

## Objetivo de aprendizado

Projeto criado para estudar PowerShell, automação,
APIs, Git e GitHub.
